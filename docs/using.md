# Using Hogwatch

## Sign in

![The sign-in page](/images/login.png)

## Overview

The overview opens your folder as a treemap: bigger blocks use more space. Click a block to go in, use the arrow to go up. **Detail** sets how many levels are drawn.

![The overview with the treemap, the list and the history chart](/images/browse-treemap.png)

The bar at the top right shows your quota use. The history card shows the size over time for the folder you are looking at, with 7 d to All ranges.

### Filters

The dashed buttons add filters: **category** (video, documents and so on, from file extensions), **age** and **size**. Filters apply to the treemap, the list and the exports. They live in the address, so you can share the link.

### List, Top files, Extensions

The **List** tab shows the children of the current folder with size, share, file count and newest file. **Top files** shows the largest files below it, and **Extensions** groups space by file type.

![Top files tab](/images/tab-top-files.png)

![Extensions tab](/images/tab-extensions.png)

### Export

**Export** downloads the tree, the top files or the usage as CSV or JSON. CSV cells that could run as spreadsheet formulas are prefixed with an apostrophe.

![The export menu](/images/export-menu.png)

## Usage

**Usage** shows what you use in total and per root, and your growth over 7, 30 or 90 days.

![The usage page](/images/usage.png)

## Listings

If an admin allowed you to list files, a folder can be listed in full. Listings expire after an hour and are not kept on the server.
